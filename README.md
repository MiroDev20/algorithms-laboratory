# Algorithms

Repositorio dedicado al estudio e implementación de algoritmos, desde los
fundamentos hasta técnicas avanzadas.

El objetivo de este proyecto no es únicamente escribir código que funcione, sino
comprender cómo y por qué funciona cada algoritmo, analizando su lógica,
eficiencia, ventajas, limitaciones y aplicaciones en problemas reales.

Cada implementación buscará ser clara, documentada y acompañada de explicaciones
para convertir este repositorio en una referencia de estudio a largo plazo.

## Objetivos

- Aprender algoritmos de forma progresiva.
- Comprender los principios detrás de cada algoritmo.
- Implementar cada algoritmo desde cero.
- Analizar complejidad temporal y espacial.
- Comparar distintas soluciones para un mismo problema.
- Mantener implementaciones limpias y fáciles de entender.
- Construir una biblioteca personal de algoritmos.

## Estructura de cada algoritmo

Cada algoritmo incluirá:

- Descripción del problema.
- Explicación paso a paso.
- Funcionamiento interno.
- Implementación.
- Complejidad temporal.
- Complejidad espacial.
- Casos de uso.
- Ventajas y desventajas.
- Referencias para seguir aprendiendo.
