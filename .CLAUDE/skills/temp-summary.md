# Temp Summary

## Objetivo

Mantener un archivo temporal llamado TEMP.md en la raíz del workspace para capturar una sinopsis breve y útil de la respuesta más reciente cuando esa información pueda servir como memoria de contexto.

---

# Cuándo aplicar esta skill

Usa esta skill cuando la conversación implique cualquiera de estos casos:

- una explicación técnica larga o con varios puntos clave
- una solución paso a paso que conviene recordar luego
- un plan de acción, checklist o propuesta de implementación
- una respuesta que probablemente será consultada más adelante

No es necesario usarla para respuestas triviales, mensajes cortos o conversaciones de seguimiento muy simples.

---

# Reglas de comportamiento

## 1. Crear o actualizar TEMP.md

- Si no existe, créalo en la raíz del workspace con el nombre exacto TEMP.md
- Si ya existe, actualízalo en lugar de crear copias nuevas
- Mantén el contenido breve, claro y fácil de revisar

## 2. Formato recomendado

Usa este formato base:

# TEMP Summary

## Resumen

Breve descripción de la idea principal o del resultado más importante.

## Puntos clave

- elemento importante 1
- elemento importante 2
- elemento importante 3

## Próximo paso

Acción recomendada o siguiente punto a revisar.

## 3. Qué incluir

Incluye únicamente lo que sea útil para retomar la conversación más adelante.

Prioriza:

- la conclusión principal
- los pasos más importantes
- decisiones relevantes
- próximos pasos o preguntas abiertas

## 4. Qué evitar

Evita:

- copiar la respuesta completa
- incluir detalles redundantes
- dejar el archivo desordenado o excesivamente largo
- añadir información irrelevante o privada

---

# Estilo de redacción

El resumen debe ser:

- conciso
- ordenado
- accionable
- fácil de leer en una pasada rápida

Si la conversación es muy compleja, el resumen puede ser un poco más detallado, pero nunca debe reemplazar la respuesta completa.

---

# Ejemplo

Si el usuario pide una explicación de un algoritmo y luego una propuesta de implementación, TEMP.md podría contener algo como:

# TEMP Summary

## Resumen

Se discutió el funcionamiento de un algoritmo y se propuso un enfoque de implementación paso a paso.

## Puntos clave

- el algoritmo resuelve el problema mediante una idea central clara
- la implementación debe priorizar claridad antes que optimización
- hay casos límite que conviene revisar antes de finalizar

## Próximo paso

Validar el enfoque con un ejemplo pequeño y luego escribir la implementación final.
